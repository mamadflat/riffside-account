# پنل عمومی 0.6.0

افزودن قرارداد نسخهٔ ۱ برای مکمل‌های مستقل: صفحه و منو، ویجت داشبورد، بخش جزئیات سفارش و فرم تنظیمات مستقل. پالت و CSS محدود به پنل نیز قابل توسعه‌اند. کنترل ورود، مالکیت سفارش و فعال‌بودن قابلیت قبل از اجرای renderer انجام می‌شود.

کد رهگیری مبتنی بر متادیتای پروژه از هسته خارج شد. نصب عمومی فقط امکانات پایه و پالت عمومی را دارد. برای حفظ رفتار اختصاصی سایت قبلی، مکمل همان پروژه همراه این نسخه نصب شود؛ داده و تنظیمات قبلی پاک یا بازنویسی نمی‌شوند.

[قرارداد و نمونهٔ توسعه](EXTENSIONS.md). WordPress 6.5+، PHP 8.0+ و WooCommerce فعال لازم است. باشگاه اختیاری و مستقل است.

## آزمون

۲۰ بررسی قرارداد مکمل‌ها و مجموعه‌های قبلی ظاهر، داشبورد، سفارش‌ها و JavaScript پاس شدند. اتصال به مکمل مستقل در وردپرس واقعی با مشتری و سفارش آزمایشی، فعال/غیرفعال‌کردن امکانات، حذف دسترسی مستقیم و حفظ تنظیمات باشگاه بررسی شد. CI روی PHP 8.0، 8.3 و 8.4 اجرا می‌شود. این انتشار شامل استقرار روی سایت اصلی نیست.

هر پروژه مخزن و بستهٔ مکمل خودش را دارد؛ مستندات عمومی هسته فقط قرارداد و مثال عمومی را نگه می‌دارند. توسعهٔ اختصاصی با کپی‌کردن یا fork هسته انجام نمی‌شود.
