# Riffside Account 0.3.0 — نسخهٔ آزمایشی مستقل

افزونهٔ پنل جدا از باشگاه نصب و به‌روزرسانی می‌شود. در این نسخه، پایهٔ مشترک UI contract 1 و پالت‌های تولیدشده از [دیزاین سیستم](https://github.com/mamadflat/riffside-design-system) داخل بسته قرار دارند. برای اجرا افزونهٔ سوم لازم نیست.

داخل پنل، باشگاه رنگ، فونت میزبان و حالت نمایش هماهنگ دارد؛ فقط یک کنترل تم نمایش داده می‌شود. غیرفعال‌کردن باشگاه، سفارش‌ها و پروفایل پنل را از دسترس خارج نمی‌کند و لینک جایگزین داشبورد نیز معتبر می‌ماند. تنظیمات مستقل باشگاه دست‌نخورده‌اند. تیکت و نمایش لایسنس مستقل و پیش‌فرض خاموش‌اند.

اعتبارسنجی: آزمون مالکیت تنظیمات و sanitize، کنترل hash بستهٔ UI، بررسی syntax همهٔ فایل‌های PHP، CI روی PHP 8.0/8.3/8.4 و ۳۶ بررسی مرورگر در نصب محلی همراه باشگاه 2.6.1. تغییر پالت و تم، موبایل و دسکتاپ، کارکرد مستقل هر افزونه و حفظ تنظیمات آزموده شد. پس از حذف دادهٔ آزمایشی، هر ۱۹ جدول بررسی‌شده با قبل برابر بود.

این release آزمایشی است؛ نصب روی سایت اصلی یا تحویل خودکار آپدیت خصوصی انجام نشده. طراحی کامل ویجت‌های جدید، مأموریت‌ها و سفارش‌ها در [نقشهٔ راه](ROADMAP.md) جداگانه پیگیری می‌شود. فایل ZIP فقط پنل را دارد؛ باشگاه بسته و نسخهٔ خودش را دارد. برای بازگشت ZIP قبلی همان افزونه را جایگزین کنید و داده‌ها را حذف نکنید.
