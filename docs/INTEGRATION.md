# راهنمای اتصال و انتشار

[English integration guide](INTEGRATION.en.md)

## ظاهر و سازگاری

پنل، قاب و ناوبری حساب واردشده را می‌سازد و درخواست را به کنترلر حساب ووکامرس می‌سپارد. صفحات فروشگاه و ورود مهمان از قالب میزبان استفاده می‌کنند. قاب حساب از `wp_head`، `wp_body_open` و `wp_footer` استفاده می‌کند. قالب‌ها می‌توانند ناوبری شناور موبایل خودشان را از طریق `riffside_account_mobile_navigation` بعد از محتوای پنل رندر کنند.

توکن‌های رنگ `--ra-*` از تنظیمات پنل می‌آیند. نسخهٔ فایل‌های مشترک `1.0.1` و نسخهٔ قرارداد `1` است. هَندل `riffside-ui-v1` فقط یک بار ثبت می‌شود. مرجع فایل‌ها و هش آن‌ها `assets/shared/riffside-ui/manifest.json` است.

`assets/sections.css` فقط برای بخش‌های داخلی حساب بارگذاری می‌شود. صفحه‌های باشگاه و داشبورد این فایل را دریافت نمی‌کنند. استایل لایسنس و دانلود بر ظاهر فرم‌ها و دکمه‌ها اعمال می‌شود. افزونهٔ ارائه‌دهنده همچنان مالک صدور، دسترسی، ثبت دامنه و تحویل فایل است. فرم‌ها و دکمه‌های ووکامرس هم از مسیرهای اصلی آن استفاده می‌کنند.

## باشگاه مشتریان

باشگاه و پنل [دیزاین سیستم مشترک](https://github.com/mamadflat/riffside-design-system) و بسته‌های مستقل دارند. داخل حساب، فیلتر `customer_club_appearance_settings` پالت‌ها و سیاست روشن/تیرهٔ پنل را به باشگاه می‌دهد. رویداد `riffside:appearance` و کلید `riffside-account-mode` تغییر تم را در همان مرورگر همگام می‌کنند.

داشبورد دادهٔ اعتبار را از `Customer_Club\Dashboard_Data::current()` می‌خواند. ثبت امتیاز و قوانین پاداش متعلق به باشگاه‌اند. باشگاه خارج از پنل تنظیمات مستقل خودش را می‌خواند.

## تب‌ها و افزونه‌های دیگر

برای متن و شورت‌کد افزونه‌های فعال، از ویرایشگر «تب‌های سفارشی» استفاده کنید. برای کد PHP، در رویداد `riffside_account_register_extensions` با API نسخهٔ ۱، صفحه، ویجت، بخش جزئیات سفارش یا تنظیمات ثبت کنید. کنترل دسترسی، nonce و پاک‌سازی خروجی عملیات افزونهٔ مکمل بر عهدهٔ همان افزونه است. [نمونهٔ کد و قرارداد کامل](EXTENSIONS.md)

## آزمون

```sh
php tests/extensions.php
php tests/appearance-contract.php
php tests/dashboard.php
php tests/dashboard-legacy.php
php tests/orders.php
php tests/theme-account.php
php tests/sections.php
node --test tests/*.test.cjs
```

برای آزمون مرورگر، یک مشتری با سفارش جاری، تکمیل‌شده و لغوشده و یک کاربر مهمان داشته باشید. سفارش دیگران، صفحه‌های خالی و پر، طرح روشن و تیره، مسیرهای مستقیم، تغییر منو، تیکت، دانلود و فرم ویرایش حساب را بررسی کنید. باشگاه را هم در کنار پنل و به‌صورت مستقل بررسی کنید.

## ساخت بسته

از ریشهٔ مخزن، یک ZIP با پوشهٔ اصلی `riffside-account/` بسازید. قواعد `.gitattributes` مستندات، آزمون‌ها و تنظیمات توسعه را از ZIP کنار می‌گذارند.

```sh
git archive --format=zip --prefix=riffside-account/ -o riffside-account-1.2.0.zip HEAD
sha256sum riffside-account-1.2.0.zip
```

برای انتشار به‌روزرسانی هر افزونه از نسخه، tag و ZIP همان مخزن استفاده کنید. برای بازگشت، ZIP نسخهٔ قبلی پنل را با همان شناسهٔ افزونه جایگزین کنید تا داده‌های سفارش، تیکت و تنظیمات سایت حفظ شوند.
