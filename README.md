# پنل کاربری ریف‌ساید

افزونهٔ مستقل پنل حساب ووکامرس؛ قابل نصب کنار [باشگاه مشتریان](https://github.com/mamadflat/customer-club). هر افزونه نسخه، بسته و چرخهٔ انتشار مستقل دارد.

## معماری اجرا

- پنل: قاب حساب، ناوبری، صفحات سفارش و تنظیمات نمایش، اتصال به ارائه‌دهندهٔ لایسنس و تیکت اختیاری.
- باشگاه: موجودی، دفتر تراکنش‌ها، قوانین پاداش، دعوت دوستان و اطلاعات باشگاه.
- [دیزاین سیستم](https://github.com/mamadflat/riffside-design-system): منبع مشترک توکن‌ها و presetها؛ **افزونهٔ سوم نیست**. خروجی نسخه‌دار آن داخل هر دو ZIP قرار دارد و نیاز به شبکه یا نصب جدا ندارد.
- داخل حساب واردشده، پنل مالک رنگ‌ها و حالت روشن/تیره است. باشگاه از همین تنظیمات استفاده می‌کند؛ تنظیمات ذخیره‌شدهٔ مستقل باشگاه تغییر نمی‌کند. بیرون از پنل یا بعد از غیرفعال‌کردن پنل، باشگاه مستقل است.
- فونت از قالب میزبان به ارث می‌رسد؛ پالت پایهٔ ریف‌ساید و رنگ‌های قابل تنظیم هر فروشگاه موجود است. صفحات حساب واردشده هدر و فوتر فروشگاه ندارند. ورود مهمان و فروشگاه از قالب میزبان استفاده می‌کنند.

نسخهٔ قابل نصب مشتری: **0.5.1**. تنظیمات یا دارایی اختصاصی مشتری در بسته وجود ندارد. [گزارش انتشار](docs/RELEASE-0.5.1.md).

## نصب و به‌روزرسانی

پیش‌نیاز پنل: WordPress 6.5+، PHP 8.0+ و WooCommerce فعال. ابتدا نسخهٔ پشتیبان بگیرید، ZIP همین افزونه را نصب و از «پنل ریف‌ساید» ظاهر و ماژول‌ها را تنظیم کنید. باشگاه اختیاری است؛ حذف یا غیرفعال‌شدن آن نباید سفارش‌ها و حساب را از کار بیندازد.

تیکت و نمایش لایسنس پیش‌فرض خاموش‌اند. لایسنس از ارائه‌دهندهٔ موجود خوانده می‌شود؛ موتور لایسنس جدیدی ساخته نمی‌شود. تغییر وضعیت ماژول، اطلاعات قبلی را پاک نمی‌کند. به‌روزرسانی از طریق ZIP مستقل انجام می‌شود؛ تحویل خودکار آپدیت خصوصی در این نسخه پیاده نشده است.
