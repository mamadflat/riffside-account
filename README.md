# پنل کاربری ریف‌ساید

افزونهٔ رایگان و متن‌باز برای حساب مشتریان ووکامرس. سفارش‌ها، دانلودها و اطلاعات حساب با داده‌ها و مسیرهای اصلی ووکامرس نمایش داده می‌شوند. رابط فارسی و راست‌به‌چپ، پالت‌های روشن و تیره و منوی کشویی موبایل دارد.

## نصب

۱. مطمئن شوید وردپرس ۶.۵ یا بالاتر، PHP ۸.۰ یا بالاتر و ووکامرس فعال دارید.
۲. فایل `riffside-account-1.0.5.zip` را از [صفحهٔ انتشار](https://github.com/mamadflat/riffside-account/releases/tag/v1.0.5) دانلود کنید.
۳. در پیشخوان، از «افزونه‌ها ← افزودن افزونهٔ تازه ← بارگذاری افزونه» فایل را نصب و فعال کنید.
۴. ظاهر و ماژول‌های اختیاری را از منوی «پنل ریف‌ساید» تنظیم کنید.

## امکانات

- داشبورد، سفارش‌ها و جزئیات سفارش مشتری در حساب کاربری
- رنگ‌های مستقل روشن و تیره، فونت قالب و منوی حساب در موبایل
- ماژول اختیاری تیکت پشتیبانی و ضمیمهٔ رمزنگاری‌شده
- اتصال اختیاری به [باشگاه مشتریان ریف‌ساید](https://github.com/mamadflat/customer-club) و ارائه‌دهندگان سازگار لایسنس
- رسید سفارش برای تسویه‌حساب کلاسیک ووکامرس

راه توسعهٔ امکانات فروشگاه در [قرارداد مکمل‌ها](docs/EXTENSIONS.md) شرح داده شده است. نمایش لایسنس به ارائه‌دهندهٔ سازگار وابسته است. افزونه در چارچوب [GPL-2.0-or-later](LICENSE.txt) منتشر می‌شود.
