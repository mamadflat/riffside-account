Free, open-source RTL customer account for WooCommerce with customizable palettes and optional support tickets.

== Description ==
Riffside Account adds a customer dashboard with order details, a mobile account drawer, independent light and dark palettes, and the host theme's font. It uses WooCommerce account routes and customer data. Optional modules provide support tickets with encrypted attachments, a Customer Club integration, and a bridge to compatible license providers. The standalone receipt uses classic WooCommerce checkout.

== Installation ==
Install and activate WooCommerce, then install and activate Riffside Account. Configure appearance and optional modules from the Riffside panel menu.
